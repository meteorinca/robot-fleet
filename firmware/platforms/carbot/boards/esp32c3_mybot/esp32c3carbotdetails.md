# ESP32-C3 CarBot Super Mini

## CarBot v1.8
CarBot has an OLED display for messages, ultrasonic sensors for distance measurements, and a L298N connected to two motors: 1 for steering (no feedback), 1 for RWD wheels. It comes built in with preprogrammed demos such as:
- Built in web server for control
- Easy GET commands to control motors, buzzer, oled, etc
- Live Readout of Ultrasonic Sensor Data on webapp and oled
- More animations on oled and audio demos using WebUI buttons and GET commands
- OTA updates for easy firmware updates
